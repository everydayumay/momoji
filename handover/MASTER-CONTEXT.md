# Pick Up! (momoji) — 마스터 컨텍스트
최종 업데이트: 2026-08-10
용도: 일반 채팅창(기획/논의 전용)에 붙여넣어 문맥을 이어받기 위한 문서.
이 문서에는 파일 접근이 필요한 지시가 없다 — 읽는 즉시 대화를 이어갈 수 있어야 한다.

---

## 역할 분리 (중요)

이 프로젝트는 두 종류의 대화창을 나눠 쓴다.

- **일반 채팅창 (지금 이 대화)**: 기획, 아이디어 논의, 우선순위 결정, 문제 진단, 의사결정 기록. 파일을 만들거나 코드를 고치지 않는다. 토큰을 아끼기 위해 도구 호출 없이 순수 대화로 진행한다.
- **Cowork 창**: 실제 코드 작업, 파일 수정, git, 배포 확인 등 "손을 쓰는" 작업 전용. 여기서는 기획 논의를 새로 시작하지 않고, 이미 이 채팅에서 정해진 걸 실행만 한다.

작업 순서: 이 채팅에서 논의 → 결정 나면 "Cowork에서 이거 해줘" 형태로 정리 → Cowork 창 열어서 실행 프롬프트 전달. Cowork 세션이 끝나면 결과를 다시 이 채팅에 요약해서 이 문서에 반영한다.

이 문서는 살아있는 문서다. 이 채팅에서 새로운 결정이 나오면 "미결정 사항"이나 "완료된 작업"을 갱신해서, 다음에 새 채팅을 열 때도 이 문서 하나로 이어받을 수 있게 유지한다.

## 앱 구조

```

/meals            식단 — 버튼으로 즉시 추천 3개 받기 (시간대 무관, 세션 내 유지)
/fridge           냉장고 — 재료 CRUD, 수량+단위(개/g/ml/봉지 등)
/schedule         일정 — 완전 빈 화면, 용도 미정
/more             더보기 — 가족 설정 / 근처 식당 / 배달 브랜드 / 통계·알림(미구현)
```

## 알려진 이슈 / 리스크

- Firestore 규칙 B안 적용에 **아내 Google 이메일이 필요한데 아직 미확보**
- 레포가 public이라 `NEXT_PUBLIC_FIREBASE_*` 값이 코드에 노출됨 (Firebase 웹 설정값 자체는 공개돼도 되는 값이지만, Firestore 규칙이 유일한 방어선이라는 점은 항상 염두에 둘 것)
- `.env.local`이 예시값으로 채워져 있어 로컬 `npm run dev`로는 로그인 테스트 불가 (배포본은 정상 동작)
- Cowork 샌드박스에서 git 명령이 가끔 불안정함 (`.git/index.lock` 삭제 권한 문제로 터미널이 막힌 사고 있었음) — Cowork 세션에는 "문제 생기면 git 건드리지 말고 코드만 작성, 사용자가 터미널에서 pull/build/commit/push" 원칙을 항상 명시할 것
- 커밋 메시지에 `!` 등 특수문자를 큰따옴표로 감싸면 bash가 `dquote>` 상태로 멈추는 사고 있었음 — 커밋 메시지는 항상 작은따옴표로 제공할 것
- 홈(자동 추천)과 식단(버튼 추천)의 기능이 지금은 사실상 겹침. 2주차에 식단이 "주간 계획"으로 바뀌면 역할이 갈라질 예정

## 알려진 이슈 / 리스크
- **Firestore 보안 규칙이 아직 A안 상태.** B안(부부 2계정 화이트리스트)으로 강화 예정이었으나 **아내 이메일을 아직 못 받음.** 오늘 세션에서 이메일 확보되면 우선 처리, 안 되면 다음으로 미룰 것
- 레포가 **public**이라 `NEXT_PUBLIC_FIREBASE_*` 값이 코드에 노출됨. Firebase 웹 설정값 자체는 공개돼도 되는 값이지만, 그만큼 Firestore 규칙이 유일한 방어선임을 항상 염두에 둘 것
- `.env.local`이 예시값(`your_api_key_here`)으로 채워져 있어 로컬 `npm run dev`로는 로그인 테스트 불가 (배포본은 정상)
- Cowork 샌드박스에서 **git 명령 실행이 불안정함** (`.git/index.lock` 등 파일에 삭제 권한이 없어 lock이 남으면 터미널까지 막힘). 세션 내에서는 git을 건드리지 말고, 코드만 작성한 뒤 사용자가 터미널에서 pull/build/commit/push 하는 방식을 기본으로 할 것
- 커밋 메시지에 `!`, `$` 등 특수문자를 큰따옴표(`"`)로 감싸면 bash가 `dquote>` 상태로 멈추는 사고가 있었음. **커밋 메시지는 항상 작은따옴표(`'`)로, 특수문자 최소화해서 제공할 것**

```

/api/recommend    → Claude API 추천 라우트
```
